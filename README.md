# 방 탈출 예약

# 기능

- 회원은 날짜, 시간, 테마를 고르고 결제를 한 후 예약할 수 있습니다.
- 관리자는 날짜, 시간, 테마, 회원을 고르고 결제 없이 예약할 수 있습니다.
- 관리자는 예약 시간을 생성할 수 있습니다.
- 관리자는 테마를 생성할 수 있습니다.
- 메인 페이지에서 최근 7일간의 인기 테마를 조회할 수 있습니다.
- 일반 회원은 관리자 페이지 / api에 접근하지 못합니다.
